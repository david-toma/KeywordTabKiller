Keyword Tab Killer

Safari extension that closes a tab the moment its URL or search contains a blocked word.

Add to AltStore Add to SideStore Download .ipa

Source URL:

After installing

  1. Open Settings → Safari → Extensions (iOS 18+: Settings → Apps → Safari → Extensions).
  2. Tap Keyword Tab Killer and turn it On.
  3. Set All Websites to Allow (and enable it for Private Browsing if you want).
  4. Open the app, add your blocked words, then browse in Safari.
